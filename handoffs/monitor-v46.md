## 1. ★★今晚最贵的一条:队列覆盖的完整机制(已定案到代码行)

qiaos插嘴：这些事情本来应该让infra agent做的，你不要学上一个agent，有事就新开一个infra session做。
- 新开session默认=chatbot, no subagent, 并且需要起名字！

【实测,我逐行读 + 5 条线独立验证】`route_check.py` 的 `merge_and_save_touched`:
```python
touched_by_id = {e.job_id: e for e in touched}   # touched = run_reroute 返回的【整个 stale snapshot】
with with_queue_lock(path):
    live = load_queue(path)
    for e in live:
        if e.job_id in touched_by_id:
            merged.append(touched_by_id[e.job_id])   # ★① 你的修改被旧对象【整体替换】
        else:
            merged.append(e)
    for e in touched:
        if e.job_id not in seen:
            merged.append(e)                          # ★② 你删掉的条目被【加回来】
    save_queue(path, merged)                          # ★无条件落盘,没有 if not touched 早退
```
★**根因**:`run_reroute` / `run_tick` 的 `return entries, log` 返回**传进去的整个 snapshot**,而不是真正 mutate 过的那些。
★**讽刺的是**:这个函数的 docstring 明写它是为了"让并发 enqueue 不再被 stale whole-queue snapshot 冲掉" —— **而喂给它的恰恰就是一整个 stale whole-queue snapshot。防护写对了,输入喂错了。**

★★**修改 vs 删除,收敛性完全不同(codi-v6 实证 + 我代码确认)**:
| 操作 | 免疫条件 | 收敛? |
|---|---|---|
| **修改** | 熬过**所有**活跃写手各一次 `load` | ★**对 reroute loop(会重新 load)收敛** |
| ★**删除** | ★**没有"熬过"这回事** —— 任何持有"该条目还存在"快照的写手都会把它加回来 | ★★**结构上不收敛** |
| ★**长距离源** | ★**一次性 CLI 在整个进程生命周期只 load 一次(L1358 在 `main()` 里)** ⇒ **你不是在等它 load 你,是在等它退出** | ★**不收敛** |

★★**maze128-v7 用预登记实验证伪了我的模型**:它的 HELD 存活 **44.6 分钟(22 个周期)后仍被打回**。⇒ **"熬过一次 load 就安全"是错的。压制哨兵不是过渡措施,是长期必需。**

★**给 infra-v11 的修法(两处一行级)**: （现在已经交接v12了，我会盯着v12让他修）
```
route_check.py  run_reroute/run_tick:  return entries → return touched(只 append 真正 mutate 的)
route_check.py  那个 "加回去" 的循环:  它是为"pass 新建的行"设计的,注释自己说 "harmless" —— ★实测一点都不 harmless
```
★★**验证判据【不要用 mtime】**(docs-v4 抓到我这个错):`save_queue` 无条件落盘 ⇒ 修好后 mtime 照跳,你会以为没修好。

## 6. ★★ 今晚提炼的判据(全部由下级实测得出,我只是转发和裁决)

**关于证据**
1. ★**"把失败渲染成一个值"这一族今晚出现 10 次**:`|| echo 0` · `grep -c` 数匹配行 · `grep -q RUNNING` 命中 `NOT_RUNNING` · `ls|grep` 近似命中 · `uptime` 读不到⇒沉默 · cache 不可读⇒判死亡 · `xmanager list` 空返回≠不存在 · `comm` 15 字符截断 · `[ -d ]` 对符号链接和真目录给同一答案 · `|| curl 兜底`保护命令失败不保护引用错对象
   ★**共同形状**:**一个【匹配/计数】工具被当成【存在性】判据 —— 把"像不像"当成"是不是"。**
   ★**修法**:fallback 哨兵值用 `-1` 不用 `0`;**把"读取是否成功"和"读到的内容说明什么"分成两层。**

### 9k. ★ 双花检测的正确方法（trm-v2 实测得出）
```

```
★**这是它 watcher 里已有的 stale 分支的镜像用法** —— 同一个判据，一个用来发现“认领是假的”，一个用来发现“认领是真的但不该发生”。
