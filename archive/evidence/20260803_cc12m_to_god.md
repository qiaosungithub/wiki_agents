## Why the move, given both cells are already metro cmh

Not locality — `mach_locality -k metro` says `cmh` for `go`, `go-d` and
`yucmhcg-d`, so by storage.md's own boundary rule the hop is free. The reason
is **quota**, and it is now the binding constraint:

- `yucmhcg-d` has **no group registration**, so it sits on the personal
  **500 GiB** per-cell ceiling and measured **398 GiB used** at planning time.
  cc12m alone costs 289 GiB at `rs=9.4`. The dataset and every future run's
  checkpoints were competing for the same ceiling.
- `go-d` is charged to `deepmind-resources-colossus`, **~5.40 PiB free**, and
  carries **`throughput_spindles = 50`** — an actual performance floor. A
  default quota circle carries ZERO spindle commitment, which is the
  documented condition behind a 12-hour collapse to 0.04 MiB/s.

Group headroom is verified only by the flex registry; `fileutil quota <group>
<cell>` reports a plausible `500.00G` for an *unregistered* group because that
is the default bucket it falls through to.

```
flex.par list_ceiling -s colossus -g deepmind-resources-colossus -l go-d
  -> Pool: deepmind-ml-flex-pool. disk = 26.1 PiB,
     throughput_spindles = 50, rodos_throughput = 162 GiB. Circle: custom.
```

## The guard: five literal asserts, every reject branch executed

| # | Checks | Exit | Proven by |
|---|---|---|---|
| 1 | Borg cell == literal `go` | 3 | ran with `BORG_CELL=yuskedq` |
| 1 | cell unreadable | 2 | ran with no `BORG_CELL` at all |
| 2 | src cell's metro == literal `cmh` | 4 | `--test_force_src_metro=xyz` |
| 3 | dst cell's metro == literal `cmh` | 4 | `--test_force_dst_metro=eu-west` |
| 2/3 | metro lookup *unknown* aborts like *wrong* | 4 | `--test_force_metro_unknown_for=go-d` |
| — | no `/bigstore/` path is ever named | 7 | `--test_force_forbidden_path=...` |
| 4 | payload x amplification fits free space | 8 | `--test_force_amplification` (can only worsen) |
| 5 | destination charged to the group | 10 | `quota_accounting_test`, both branches |

The metro is **queried live** from the machine-locality library, so ASSERT 2/3
are queries rather than guesses about what a cell name looks like. Every test
hook is fail-closed by construction — it discards the real answer, so it can
only ever cause an abort, never relax the guard.

`//cloud/bigstore/util:bigstore_file_register` is deliberately **absent** from
the BUILD deps, so a `/bigstore/` path in this process is an ordinary POSIX
path that does not exist. The string checks are the diagnosable layer; the
omission is the one that holds even if that code is edited away.

## Notes worth keeping

- **Throughput was half the reverse direction** (680 vs 1338 MiB/s) for the
  same payload between the same two cells. Not investigated; both are far
  above the 3.0 MiB/s floor and neither is near a collapse. Per-object median
  was low (0.24 MiB/s) because the 150 tiny sidecars dominate the count while
  contributing no bytes — read the aggregate, not the median, for a mixed set.
- **`fileutil test` has no `-e` flag.** It errors with "Unknown command line
  flag 'e'", so a script using `test -e` sees every path as missing. Use `-f`
  (file) or `-d` (directory).
- The model files are named explicitly rather than globbed: a glob would
  silently copy whatever else lands in that directory later.
